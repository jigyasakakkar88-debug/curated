API cheat sheet: what each request does

GET = "give me something": only reads, changes nothing, safe to repeat. POST = "act on this": changes data, costs money or does work. Rule of thumb: judge by the effect on your system, not by what the backend fetches behind the scenes.

POST/api/stylistSends the shopper's question and chat; the backend runs Claude with the tools and returns the answer and products (costs ₹ and logs a trace).
POST/api/stylist?browse=1"See all matches": the next page of products for the same search (keyword search only, no AI cost).
POST/api/stylist?feedback=1Saves a 👍/👎 on an answer.
GET/api/productsThe shop page asks for the full product feed to display.
GET/api/catalogShows the Algolia index status (how many products, when last synced).
POST/api/catalogSync: pulls every brand's products from Shopify and updates Algolia; or Freeze: saves a fixed copy for evals.
GET/api/policiesShows the brand policies already stored in policies.json.
POST/api/policiesFetch the brands' policy pages, have Haiku extract the facts, or save your edits (rewrites policies.json).
GET/api/insightsShows traces and KPIs, eval runs, one run's answers, the test questions or the relevance labels.
POST/api/insightsStarts or continues an eval run, saves a grade, or builds and saves relevance labels.
POST/api/discoverStarts a Brand Scout run: Claude searches the web for new brands to suggest.
GET/api/recommendationsShows Brand Scout's suggestions waiting for your decision.
POST/api/recommendationsAccept a suggestion (adds the brand to brands.json) or reject it.

Say it in one breath

  • "A static frontend calls a serverless REST backend on Vercel. The backend runs a Claude agent with tools, searches products in Algolia, keeps small config and eval data as JSON in GitHub, and pulls catalogs from Shopify."

Why JSON in GitHub is enough (for now)

  • Small: 23 brands, a few hundred KB of policies
  • Changes rarely, with one writer (the admin)
  • Simple reads: load the whole file
  • Free version history of every change

When to switch

  • User accounts, synced wishlists, orders, many writers → Postgres
  • Search by meaning → a vector index (Algolia NeuralSearch, Pinecone or pgvector)
  • High-volume traces and metrics → an analytics store

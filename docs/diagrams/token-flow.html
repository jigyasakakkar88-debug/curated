What it can't fix

  • The reranker only sees Algolia's top 150. A great piece described in other words never reaches it. That's the job of offline tagging (occasion, formality) and, later, semantic search.
  • It reads text, not photos. Adding photos would improve judgement on style but cost several times more.

How we'll know it's worth it

  • Same frozen catalog, same 22 questions: run C, then C + rerank.
  • Compare recall, precision, nDCG and your rubric score against ₹ per answer and time.
  • Ship it only if quality rises enough to justify +₹2.3 and +5 s.
